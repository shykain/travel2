云十五·悦美 昆大丽6日纯玩游（2-15人小团）

产品理念：兼顾美景与舒适，用轻松的步调邂逅云南，在山水与烟火间，把度假感融入每一段风景，尽享旅途的惬意与自在。让度假不止打卡，更有治愈与享受。

🏨
住宿标准携程3钻+首住1晚四钻+大理1晚海景酒店
🍜
用餐标准5早5正（正餐30元/人）
👥
成团人数2-15成人精品小团
🚗
出发时间每天早上8:00
Day 1 各地 → 昆明 起始地乘机 → 昆明长水机场 → 入住酒店
早 ×中 ×晚 ×
🏨 住宿：昆明

各地旅客乘飞机抵达昆明，由商务专车接至安排的酒店办理入住。时间允许的情况下，推荐自行前往游览昆明地标"陆军讲武堂"，品尝云南特色小吃：特色臭豆腐、小锅米线、各类果汁，感受"春城"气息。

Day 2 昆明 → 楚雄 西山风景区 → 茶马花街 → 四季盲盒 → 楚雄（威楚传奇+长街宴+祭火大典）
早 √中 ×晚 √
🏨 住宿：楚雄

酒店早餐后8:00乘车赴西山风景区（游览约90分钟，不含景区环保大巴+索道+电瓶车60元/人）。西山峰峦起伏，林木苍翠，远眺如"卧佛山"又称"睡美人"。随后前往网红打卡地茶马花街（约30分钟），自由品尝昆明地道豆花米线、烧烤、红糖粑粑等，中餐自由安排。

惊喜体验旅游四季盲盒（约45分钟，随机属性），以全年季节限定旅行体验、目的地盲选或网红打卡项目，盲盒打开地可能在昆明、大理或丽江。

之后乘车赴"中国火城"——楚雄，观看大型户外实景沉浸式演艺秀《威楚传奇》，剧本改编自楚雄彝族历史传说，讲述彝族姑娘阿表妹与小伙阿表哥的感人爱情故事，集文化、演艺、餐饮为一体。入住楚雄酒店。

Day 3 大理 · 洱海深度游 圣托里尼·理想邦 → 洱海私人游艇 → 音乐大篷车 → 网红S湾（旅拍）
早 √中 √晚 √
🏨 住宿：大理（海景酒店）

早餐后8:00乘车前往大理，游览圣托里尼·理想邦（约60分钟）。直面苍山洱海，地中海蓝白相间色调，不出国门体验希腊风情，绝美大片直出。

午餐后尊享乘坐明星同款洱海私人游艇（约30分钟），跟随"跑男"脚步，在专属游艇上与洱海近距离接触，观苍洱山水，看"金梭烟云"。

随后乘坐音乐大篷车（专业民谣歌手），移动的音乐主题巡游车，每台车配专职民谣驻唱歌手，可点歌也可自己唱歌。

游览网红S湾（赠送时尚旅拍，每组家庭赠8张电子版照片，约60分钟），每一步都是风景，可散步或骑行，看潮起潮落、云卷云舒。

晚餐欣赏非遗传承美食大秀《南涧跳菜》，后入住大理酒店。

Day 4 大理 → 丽江 大理古城 → 玉龙雪山（云杉坪索道）→ 蓝月谷 → 丽江古城
早 √中 √晚 ×
🏨 住宿：丽江

早餐后8:00乘车游览大理古城（约120分钟，开放式古城自由活动）。漫步青石街道，品味风花雪月之地的惬意与感动。

午餐后前往丽江游览国家5A级景区玉龙雪山风景区（含排队约210分钟），乘坐云杉坪索道直达海拔3240米的云杉坪，观赏云杉树林、高山草甸与玉龙雪峰。

游览蓝月谷（不含电瓶车60元/人）、白水河、甘海子，玉龙雪山水流经此地，因地表矿物质幻化出迷人色彩。

游览世界文化遗产丽江古城及网红街（开放式自由活动），寻味小桥流水的闲适与浪漫。晚餐自理，可品尝古城内小吃美食，游览结束自行返回酒店。

温馨提示：玉龙雪山索道受风季、限流、维修等不可抗因素影响无法乘坐时，我社根据实际情况安排或改无索道并现退差价；可补差价升级冰川公园大索道（需提前预订，行程中不接受升级）。雪山防寒服50元/件、氧气60元/瓶，敬请自理。
Day 5 丽江 → 昆明 束河古镇 → 洱海观景台 → 返回昆明
早 √中 √晚 ×
🏨 住宿：昆明

早餐后8:00乘车游览国家4A级景区束河古镇（约60分钟），"世界文化遗产"丽江古城重要组成部分，保存完好的古道、集市及近千幢传统民居，古色古香。

午餐后乘车前往洱海观景台（约15分钟），观苍山看洱海，尽享风花雪月。行程结束后乘车返回昆明，抵达后入住酒店休息。

Day 6 昆明 → 返程 集散中心 → 昆明长水国际机场 → 温馨的家
早 √中 ×晚 ×
🏨 住宿：无

早餐后前往游客集散中心（约90分钟），根据航班时间送至昆明长水国际机场，返回温馨的家。『云十五·悦美』期待您常来云南。

温馨提示：13点以前航班因时间关系无法安排集散中心，无退费。返程前请仔细整理行李物品及证件，核对航班时间。

Day 1 各地 → 昆明 昆明接机 → 自由活动 → 入住酒店
早 ×中 ×晚 ×
🏨 住宿：昆明

出团前一天将有接机信息发送到您手机。各地至昆明后，专业工作人员接机/接站，带您前往入住指定备选酒店休息和自由活动。

Day 2 昆明 → 楚雄 西山景区 → 滇池海埂大坝 → 茶马花街 → 彝族长街宴（篝火晚会）
早 √中 ×晚 √
🏨 住宿：楚雄

早餐后8:00出发，乘车游览西山景区（不含往返景区电瓶车自费60元/人），有"睡美人"之称。登龙门，感受古人智慧与巧夺天工。西山脚下网红打卡点茶马花街，自行品尝烤豆腐、红糖粑粑、台湾食吧、音乐咖啡西餐，午餐自由安排。

餐后前往滇池海埂大坝，观"高原明珠"滇池，眺望"睡美人"西山，与海鸥精灵互动（10月-3月为看海鸥季节）。

随后乘车前往楚雄，享受彝乡彝族长街宴与祭火大典·篝火晚会，品彝族特色美食，喝醇香彝族土家酒，欣赏霸道敬酒歌，跟随彝族儿女跳起"大三弦"舞，沉浸在火海、歌海及舞海中。

Day 3 楚雄 → 大理 圣托里尼·理想邦 → 喜洲音乐酒吧车 → 非遗甲马手作 → 航拍+洱海旅拍 → 洱海骑行 → 鲜花宴
早 √中 √晚 √
🏨 住宿：大理（海景酒店）

早餐后8:00出发前往大理网红景点、洱海的城堡——圣托里尼·理想邦。依山而建，街道诗意蜿蜒，面朝洱海春暖花开，居所与自然极美融合。

午餐后乘坐喜洲音乐酒吧车，解锁文艺大理——移动的音乐巡游车，搭载专业歌手献唱。

前往非遗甲马手作体验（30分钟），学习1300年非遗文化技艺，亲手印一张非遗甲马。甲马融合木刻版画与纸符，承载民间信仰，被誉为"人神信使"。

赠送航拍+洱海旅拍（每组家庭赠3-5张电子照片+一条团队航拍视频）。后前往最美转角——洱海生态廊道洱海骑行（不使用不退费），S湾每走一步都是风景。

晚餐安排浪漫鲜花宴，以云南特色食用鲜花为食材，领略七彩云南和飞花春城风情。入住大理酒店。

Day 4 大理 → 丽江 大理古城 → 玉龙雪山（云杉坪）→ 蓝月谷 → 丽江古城
早 √中 √晚 ×
🏨 住宿：丽江

早餐后8:00乘车至大理古城，青石板路蜿蜒，古色古香的建筑白墙黛瓦，南诏古国历史的缩影。

中餐后乘车前往国家5A级景区玉龙雪山，被誉为"东方瑞士"的"天然冰川博物馆"，离赤道最近的雪山群，主峰扇子陡海拔5596米。一路游览甘海子、白水河、蓝月谷（60-90分钟），乘小索道游览云杉坪（含小索道费及环保车，蓝月谷电瓶车自理60元/人）。

可自费观看演出《千古情》或《丽水金沙》。游览丽江古城（开放式景点），流水小桥人家宛若江南，自行品尝古城小吃，游览结束自行返回酒店。

温馨提示：云杉坪索道因限流、风季停开、维修等不可抗因素无法乘坐时，我社会根据索道公司政策退还费用。可升级玉龙雪山大索道（差价100元/人，不接受临时升级，不保证成功）。
Day 5 丽江 → 昆明 束河古镇 → 洱海观景台 → 返回昆明
早 √中 √晚 ×
🏨 住宿：昆明

早餐后8:00出发前往束河古镇，纳西语称"绍坞"，意为"高峰之下的村寨"，是纳西先民最早聚居地之一，茶马古道上保存完好的重要集镇。古朴建筑、繁华步行街，小溪流穿过居民区，可随意漫步感受慢时光。

随后前往洱海观景台，俯瞰洱海和苍山的绝佳位置，视野开阔，洱海全貌与苍山雄伟尽收眼底。结束后乘车返回昆明，入住酒店。

Day 6 昆明 → 返程 游客集散中心 → 送机 → 始发地
早 √中 ×晚 ×
🏨 住宿：无

早餐后前往游客集散中心，根据航班时间送至昆明长水国际机场，返回温馨的家（请预定14点以后起飞的航班）。

温馨提示：返程仔细整理好行李物品及证件，不要有所遗漏，核对航班时间，避免不必要的麻烦。
