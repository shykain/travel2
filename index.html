每日安排，一目了然

云十五·悦美 昆大丽6日纯玩游（2-15人小团）

兼顾美景与舒适，用轻松的步调邂逅云南，在山水与烟火间，把度假感融入每一段风景。

🍜
用餐5早5正（正餐30元/人）
👥
人数2-15成人精品小团
🚗
出发每天早上8:00
Day 1各地 → 昆明 起始地乘机 → 昆明长水机场 → 入住酒店
早 ×中 ×晚 ×
🏨 住宿：昆明

各地旅客乘飞机抵达昆明，由商务专车接至安排的酒店办理入住。时间允许推荐自行游览"陆军讲武堂"，品尝臭豆腐、小锅米线、各类果汁，感受"春城"气息。

Day 2昆明 → 楚雄 西山风景区 → 茶马花街 → 四季盲盒 → 威楚传奇+长街宴+祭火大典
早 √中 ×晚 √
🏨 住宿：楚雄

早餐后8:00乘车赴西山风景区（约90分钟，不含环保大巴+索道+电瓶车60元/人）。西山峰峦起伏，远眺如"卧佛山"又称"睡美人"。随后前往茶马花街自由品尝豆花米线、烧烤、红糖粑粑等。

惊喜体验旅游四季盲盒（约45分钟），随机属性，盲盒打开地可能在昆明、大理或丽江。

之后乘车赴楚雄，观看大型户外实景沉浸式演艺秀《威楚传奇》，讲述彝族姑娘阿表妹与小伙阿表哥的感人爱情故事，集文化、演艺、餐饮为一体。入住楚雄酒店。

Day 3大理 · 洱海深度游 圣托里尼·理想邦 → 洱海私人游艇 → 音乐大篷车 → 网红S湾（旅拍）
早 √中 √晚 √
🏨 住宿：大理（海景酒店）

早餐后8:00前往大理，游览圣托里尼·理想邦（约60分钟），直面苍山洱海，地中海蓝白相间色调，不出国门体验希腊风情。

午餐后尊享洱海私人游艇（约30分钟），跟随"跑男"脚步，观苍洱山水，看"金梭烟云"。

乘坐音乐大篷车（专业民谣歌手），移动的音乐主题巡游车，可点歌也可自己唱歌。

游览网红S湾（赠送旅拍，每组家庭赠8张电子照片，约60分钟），可散步或骑行。

晚餐欣赏非遗传承美食大秀《南涧跳菜》，后入住大理酒店。

Day 4大理 → 丽江 大理古城 → 玉龙雪山（云杉坪索道）→ 蓝月谷 → 丽江古城
早 √中 √晚 ×
🏨 住宿：丽江

早餐后8:00游览大理古城（约120分钟），漫步青石街道，品味风花雪月之地。

午餐后前往国家5A级景区玉龙雪山风景区（约210分钟），乘云杉坪索道直达海拔3240米，观赏云杉树林、高山草甸与玉龙雪峰。

游览蓝月谷（不含电瓶车60元/人）、白水河、甘海子。

游览世界文化遗产丽江古城及网红街，寻味小桥流水的闲适与浪漫。晚餐自理，可品尝古城小吃。

玉龙雪山索道受风季、限流等不可抗因素影响无法乘坐时退差价；可补差价升级冰川公园大索道。防寒服50元/件、氧气60元/瓶自理。
Day 5丽江 → 昆明 束河古镇 → 洱海观景台 → 返回昆明
早 √中 √晚 ×
🏨 住宿：昆明

早餐后8:00游览国家4A级景区束河古镇（约60分钟），保存完好的古道、集市及近千幢传统民居，古色古香。

午餐后前往洱海观景台（约15分钟），观苍山看洱海，尽享风花雪月。乘车返回昆明入住酒店。

Day 6昆明 → 返程 集散中心 → 昆明长水机场 → 温馨的家
早 √中 ×晚 ×
🏨 住宿：无

早餐后前往游客集散中心（约90分钟），根据航班时间送至昆明长水国际机场，返回温馨的家。

13点以前航班无法安排集散中心，无退费。请核对航班时间，提前到机场办理登机手续。

出团前一天将有接机信息发送到您手机。各地至昆明后，专业工作人员接机/接站，带您前往入住指定备选酒店休息和自由活动。

Day 2昆明 → 楚雄 西山景区 → 滇池海埂大坝 → 茶马花街 → 彝族长街宴（篝火晚会）
早 √中 ×晚 √
🏨 住宿：楚雄

早餐后8:00游览西山景区（不含电瓶车60元/人），有"睡美人"之称。登龙门，感受古人智慧。茶马花街自由品尝烤豆腐、红糖粑粑等。

前往滇池海埂大坝，观"高原明珠"滇池，与海鸥精灵互动（10月-3月看海鸥季节）。

乘车前往楚雄，享受彝族长街宴与祭火大典·篝火晚会，品彝族美食，喝土家酒，跳"大三弦"舞，沉浸在火海、歌海及舞海中。

Day 3楚雄 → 大理 圣托里尼·理想邦 → 喜洲音乐酒吧车 → 非遗甲马手作 → 航拍+旅拍 → 洱海骑行 → 鲜花宴
早 √中 √晚 √
🏨 住宿：大理（海景酒店）

8:00出发前往圣托里尼·理想邦，依山而建，面朝洱海春暖花开。

乘坐喜洲音乐酒吧车，移动的音乐巡游车，搭载专业歌手献唱。

非遗甲马手作体验（30分钟），学习1300年非遗文化技艺，亲手印一张非遗甲马。

赠送航拍+洱海旅拍（每组家庭赠3-5张照片+一条航拍视频）。前往最美转角洱海骑行，S湾每走一步都是风景。

晚餐安排浪漫鲜花宴，以云南特色食用鲜花为食材。入住大理酒店。

Day 4大理 → 丽江 大理古城 → 玉龙雪山（云杉坪）→ 蓝月谷 → 丽江古城
早 √中 √晚 ×
🏨 住宿：丽江

8:00乘车至大理古城，青石板路蜿蜒，白墙黛瓦，南诏古国历史的缩影。

中餐后前往国家5A级景区玉龙雪山，"东方瑞士"的"天然冰川博物馆"，主峰扇子陡海拔5596米。游览甘海子、白水河、蓝月谷（60-90分钟），乘小索道游览云杉坪。

可自费观看《千古情》或《丽水金沙》。游览丽江古城，流水小桥人家宛若江南，自行品尝古城小吃。

云杉坪索道因限流、风季停开等不可抗因素无法乘坐时退还费用。可升级大索道（差价100元/人）。
Day 5丽江 → 昆明 束河古镇 → 洱海观景台 → 返回昆明
早 √中 √晚 ×
🏨 住宿：昆明

8:00前往束河古镇，纳西语称"绍坞"，意为"高峰之下的村寨"，茶马古道上保存完好的重要集镇。小溪流穿过居民区，可随意漫步感受慢时光。

前往洱海观景台，俯瞰洱海和苍山的绝佳位置。结束后乘车返回昆明，入住酒店。

Day 6昆明 → 返程 游客集散中心 → 送机 → 始发地
早 √中 ×晚 ×
🏨 住宿：无

早餐后前往游客集散中心，根据航班时间送至昆明长水国际机场，返回温馨的家（请预定14点以后航班）。

返程仔细整理行李物品及证件，核对航班时间，避免不必要的麻烦。

出行须知

  • 云南属高原地区，有心脏病、高血压、孕妇等不适合高原活动群体建议不要选择此产品。
  • 行程中如有头晕、呼吸困难等症状，请及时告知随团导游。
  • 昼夜温差大，请带足保暖防寒衣物；紫外线强，请备好防晒用品。
  • 请尊重当地各民族的风俗习惯和宗教信仰。
  • 团队游览期间擅自离团视同违约，旅行社服务关系自动终止。
  • 车程较长，请自备充饥食品和防晕车药品。
  • 上坡时车速有时仅20-30迈，敬请谅解。
  • 当地带空调的酒店空调均定时开放。
  • 出行必备：雨衣/雨伞、运动鞋、感冒药、肠胃药、防晒油、太阳帽等。
  • 旅游景区人流量较大，请保管好个人财物。
  • 选择美食时请选择干净卫生的场所用餐。
  • 返程前请仔细整理行李物品及证件，核对航班时间。
